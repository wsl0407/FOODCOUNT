# FOODCOUNT 每日午晚餐計算機

減脂期用的午餐／晚餐計算機：價錢、熱量、蛋白質、飽足感一次算。

- 食材分為澱粉主食、蛋白質主菜、蔬菜配菜、乳品飲品、油脂醬料（參考營養師 Tracy〈好市多減脂採買清單〉）
- 價格：2026/11/11 好市多線上購物（含運）與全聯小時達（店內價）標價換算成每 100g，有特價時取原價
- 飽足分：份量（目標 450g）40%、蛋白質（每日目標的一半）35%、纖維（目標 8g）25%
- 「幫我配一餐」：在熱量、蛋白質、預算限制下，找出最飽、同分最便宜的組合

直接用瀏覽器打開 `index.html` 即可使用，資料存在瀏覽器的 localStorage。

本工具僅供估算，不是醫療建議。
